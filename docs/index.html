The table story

Build the shell, then add features.

The sample clones spec.tableWithFooter, fills its table sections and search toolbar with single steps, then calls multi groups for the serial and action columns.

01 / SERIAL SETUP

Coordinate the edges

set-serial prepends a width, header cell, and footer cell. The sample follows with a single step that fills each body row.

02 / OPTIONS COLUMN

Add the row button

The options group adds a width and header, pushes a button into each body row, and adds its footer cell.

03 / EDIT COLUMN

Repeat the coordinated pattern

The edit group applies the same four-part table change using the edit-specific templates.

SET-SERIALwidth · header · footer
SINGLE STEPserial cell per row
OPTIONSwidth · header · rows · footer
EDITwidth · header · rows · footer
Three groups used

Each key describes a table feature.

A multi descriptor expands to its ordered array of template insertions against the current base table.

Serial is completed across both reports

The multi group adds serial width, header, and footer. The sample’s next reference, { type: "single", key: "serial-show-serial" }, inserts the numbered cells into the existing body rows. Together, those references make the serial column complete.
