Report 02 · Multi-step feature pattern

One feature.
Every coordinated change.

Report features often span several destinations. This package groups their ordered transformations together, so a serial column or action column is described as one understandable unit.

The story

Describe the whole feature.

The sibling single report makes one transformation easy to inspect. This report keeps related transformations together when they work as a set.

01 / NAME

Start with the feature

Keys such as serial and options-show-edit-button describe the change a report can enable.

02 / SEQUENCE

Order the destinations

Each array lists the component edits in sequence: widths, headers, row cells, and footer cells.

03 / REUSE

Keep the steps declarative

Every step still names its destination, action, and template. The feature group adds coordination, not imperative renderer code.

STEP 02Prepend the header cell

How to read it

The array is the bundle. Each entry is a transformation step, and its destination JSONPath identifies the tree node to update. A feature can therefore coordinate several parts of one report while keeping every operation inspectable. The renderer and template definitions remain in their companion packages.
