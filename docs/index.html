The group story

Keep coordinated writes together.

Each key maps to an ordered array. The runner applies its child steps to the current state before moving to the next instruction reference.

V4 catalog

Each key names one coordinated job.

Some groups use static template actions; card groups use a transformation function and data source. The package defines these steps but does not execute them.

Example descriptortype: multi
{ type: "multi", key: "options-serial" }
The serial group is complete

In V4, options-serial includes the body-row numbering as well as its width, header, and footer. The runner applies all four child steps in their declared order.
Use a group

Reference the key; let the runner execute its steps.

A multi descriptor selects this package’s array. The consuming runner shares its current state with every atomic step in the group.

Instruction dataV4 group shape
import multiInstructions from "declarative-instructions-multi";

const serialSteps = multiInstructions["options-serial"];
// serialSteps contains four ordered writes

const descriptor = { type: "multi", key: "options-serial" };

The catalog describes the feature. A step runner supplies the state, applies each child instruction, and continues with the next descriptor.
